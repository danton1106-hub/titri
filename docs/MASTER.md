# MASTER — архитектура «титры»

## Продукт

Бесплатный навигатор по фильмам и сериалам. Главный вопрос сайта: **что выходит, когда выходит и где смотреть.** Ядро — календарь премьер и графики выхода серий. Каталог вторичен.

Всё основное бесплатно: календари, графики, карточки, статьи. Ничего не закрывается подпиской. Монетизация — реклама, партнёрские интеграции, SEO-трафик. Не платный доступ.

## Стек

Next.js 15 (App Router, TypeScript) • Tailwind v4 (токены из DESIGN.md) • Supabase/PostgreSQL • Vercel + Cron • изображения с CDN TMDB • статьи в таблице `articles` • GA + Яндекс Метрика • поиск сначала через Postgres FTS, позже Typesense.

## URL

```
/                                   главная
/calendar/2026/october              календарь месяца
/series/[slug]                      сериал
/series/[slug]/season-[n]           сезон + график серий
/movies/[slug]                      фильм
/articles/[slug]                    статья
/collections/[slug]                 автоподборки («Аниме 2026», «Русские сериалы»)
```

Slug строится из латинского названия и после публикации не меняется. При коллизиях добавляется `-[год]`.

# Источники данных

**Принцип: только легальные источники с явной лицензией.** Никаких парсеров чужих сайтов, никаких неофициальных API, никаких данных «в серой зоне». Если у источника нет публичного API и он не разрешает автоматический сбор — он не используется. Это решение зафиксировано и не пересматривается ради полноты базы.

## Основа

| Источник | Что берём | Доступ | Лицензия / условия |
|---|---|---|---|
| **TMDB** | Фильмы, сериалы, сезоны, эпизоды, даты, постеры, кадры, жанры, русские названия и описания, трейлеры, площадки (через JustWatch) | Бесплатный ключ | Обязательна атрибуция: логотип TMDB и текст «данный продукт использует TMDB API, но не одобрен и не сертифицирован TMDB» |
| **TVMaze** | Расписание эфира, web/streaming-каналы, будущие серии | Бесплатно, без ключа | Ссылка на TVMaze при показе данных |
| **Wikidata** | Факты, связи, даты, страны, студии | Бесплатно, без ключа | **CC0** — ограничений нет |
| **OMDb** | Рейтинги IMDb и Rotten Tomatoes | Бесплатный тариф | Указание источника |
| **Trakt** | Календари, тренды, «популярное за неделю» | Бесплатный ключ | Указание источника |

**JustWatch:** данные о площадках приходят через TMDB, но требуют **отдельной атрибуции JustWatch** при отображении. Строку в интерфейсе не убирать.

## Аниме и мультфильмы

| Источник | Что берём | Доступ | Лицензия |
|---|---|---|---|
| **AniList** | GraphQL, календарь выхода, сезонные чарты, связи | Бесплатно, без ключа | Указание источника |
| **Jikan v4** | Обёртка над MyAnimeList: студии, эпизоды, оценки | Бесплатно, без ключа, лимит ~3 запроса/сек | Данные MyAnimeList, указание источника |
| **Shikimori** | **Русские названия аниме, русские оценки, студии, статусы** | API, часть методов по OAuth | Указание источника; уточнить условия перед продакшеном |
| **Kitsu** | JSON:API, альтернатива AniList | Бесплатно | Указание источника |

**Мультфильмы** отдельным источником не нужны — размечаются внутри TMDB: `with_genres=16`.

**Аниме:** `with_genres=16` + `with_origin_country=JP`, либо связка с Shikimori/AniList по ID.

**Про Shikimori отдельно.** Это единственный источник с полноценными русскими названиями аниме. Ни AniList, ни MyAnimeList их в нужном объёме не дают. Перед подключением в продакшене — прочитать их условия использования и написать в поддержку, если что-то неясно. Без подтверждения в продакшене не использовать.

## Русский контент

**Честная оценка: полноценного легального источника русских фильмов и сериалов с открытым API не существует.**

| Источник | Статус | Решение |
|---|---|---|
| **TMDB с `language=ru-RU`** | Русские названия для того, что есть в базе | **Используем.** Покрытие неполное |
| **Wikidata** | Факты по российским фильмам и сериалам | **Используем.** CC0 |
| **Админка** | Ручное дозаполнение дыр | **Используем.** Основной способ закрыть пробелы |
| Kinopoisk API Unofficial | Неофициальный, данные принадлежат Кинопоиску | **Не используем** |
| Кинопоиск официальный API | Только по партнёрскому договору | Не сейчас; возможен позже при партнёрстве |
| Иви, Okko, Wink, Premier | Публичных API нет | Не используем; возможен партнёрский договор |
| Кино-Театр.ру, парсинг | Сбор запрещён условиями | **Не используем** |

**Как закрываем дыры без нарушений:**

1. TMDB как база — берём всё, что там есть на русском.
2. Wikidata для фактов, которых нет в TMDB: даты, страны, студии, состав.
3. **Ручное дозаполнение через админку** — русские названия, описания, постеры. Это не «костыль», а нормальная практика: вручную дозаполненная база становится собственным активом, который есть не у всех.
4. Позже — прямые договоры с площадками и студиями, когда появится трафик.

Текущее покрытие русского контента нужно замерить: сколько российских релизов есть в TMDB, сколько из них с русскими названиями. После замера станет ясно, какой объём ручной работы предстоит.

## Фильтры

| Фильтр | Параметр TMDB |
|---|---|
| Мультфильмы | `with_genres=16` |
| Аниме | `with_genres=16` + `with_origin_country=JP` |
| Российское | `with_origin_country=RU` / `with_original_language=ru` |
| Корейское, турецкое и др. | `with_origin_country=KR` / `TR` |
| Жанры | `with_genres=18,80` (запятая = И, `\|` = ИЛИ) |
| Исключить жанр | `without_genres` |
| Площадка | `with_watch_providers` + `watch_region=RU` |
| Год, рейтинг, длительность | `first_air_date.gte`, `vote_average.gte`, `with_runtime.lte` |
| Студия | `with_companies` |

Сохранённые комбинации под SEO, каждая — отдельная посадочная страница: «Аниме 2026», «Русские сериалы», «Мультфильмы для детей», «Новые сериалы на Okko».

## Обновление данных

Вебхуков ни TMDB, ни TVMaze не дают — только опрос по расписанию.

| Механизм | Частота | Что делает |
|---|---|---|
| `/tv/changes`, `/movie/changes` | каждые 6 часов | Только дельта: что изменилось. Основной механизм |
| `on_the_air`, `airing_today` | каждые 6 часов | Актуальные серии |
| `discover` на ±60 дней | каждые 6 часов | Премьеры и будущие сезоны |
| TVMaze schedule | раз в сутки | Сверка дат эфира с TMDB |
| Первичная заливка | однократно | Список ID из ежедневных выгрузок TMDB |

При расхождении дат TMDB и TVMaze хранить обе и показывать ту, что пришла из источника с более свежим обновлением.

# Статьи

## Модель

**Только собственная редакция.** Никакого машинного перевода чужих статей и никакого копирования. Формат:

- **Пересказ своими словами**, 2–4 абзаца. Факты — свободны, форма изложения — своя.
- **Материал по нескольким источникам.** Новость из трёх изданий → один собственный текст.
- **Пресс-релизы студий** — распространяются именно для публикации.
- **Собственные материалы:** разборы, объяснения концовок, подборки, пасхалки.

Каждая статья ссылается на первоисточники. Это и корректно, и полезно для доверия.

## Почему не перевод

Два независимых риска, оба серьёзные:

1. **Правовой.** Перевод — производное произведение, требует разрешения правообладателя. Факты не охраняются, форма изложения охраняется.
2. **Поисковый.** Google относит массовый машинный перевод к «scaled content abuse». Тот же фильтр, что и у потока сгенерированных SEO-страниц.

## Тон

Стиль — **резковатый и чуть наглый**. Не корпоративная пресс-релизная нейтральность. Автор имеет мнение и говорит его прямо. При этом не хамство и не радикализм ради эффекта.

**Как это звучит:**

| Плохо (никакой подачи) | Хорошо (наш тон) |
|---|---|
| «Сериал продлён на третий сезон. Премьера состоится в 2027 году.» | «Продлили. Третий сезон выйдет в 2027-м — так что откладывайте повторный пересмотр, время ещё есть.» |
| «Аниме получило высокие оценки критиков.» | «Оценки высокие, но это тот случай, когда критики смотрели внимательнее, чем зрители.» |
| «Платформа анонсировала новый проект.» | «Ещё один проект, о котором мы ничего не знаем, кроме одного кадра и имени шоураннера.» |
| «Фильм показывает хорошие результаты в прокате.» | «Касса говорит одно: зрители пришли. Остальное — вопрос вкуса.» |

**Правила тона:**

- Оценка важнее пересказа. Читатель может узнать новость где угодно; наша ценность — в том, что мы об этом думаем.
- Короткие предложения. Никаких «в рамках данного проекта».
- Разговорное обращение к читателю, но без панибратства.
- Не выдумывать факты ради остроты. Мнение — да, выдумка — нет.
- Не унижать людей и не переходить на личности. Можно критиковать сериал, нельзя — зрителей или авторов.
- Заголовки прямые и без вопросительных знаков и «шок-контента».

## Источники статей (RSS)

RSS используем **как повод для собственного текста**, а не как текст для перевода.

**Зарубежные:** Variety, Deadline, The Hollywood Reporter, IndieWire, ScreenDaily, Collider, /Film.
**Русские:** КГ-Портал, Film.ru, InterMedia, ProfiCinema, Бюллетень кинопрокатчика, Кино-Театр.ру.
**Универсально:** Google News RSS по запросам.

Обязательно читать условия каждого фида: часть изданий разрешает только личное использование RSS.

## Пайплайн

1. Cron забирает фиды.
2. Дедупликация по заголовку и ссылке.
3. Фильтр релевантности: только фильмы, сериалы, аниме.
4. Привязка к сущностям базы (сериал, фильм, персона).
5. **Создание черновика**, а не публикация: факты, ссылки на источники, заметка для автора.
6. Человек пишет текст и нажимает «опубликовать».

Автоматическая публикация без человека не допускается. ИИ может помочь с черновиком и переводом фактов, но финальный текст — редакционный.

# БД

`series`, `seasons`, `episodes`, `movies`, `people`, `genres`, `providers`, `release_dates` (тип: premiere/theatrical/digital/physical/tv + регион), `articles`, `article_series`, `article_movies`, `article_sources`, `seo_metadata`.

Во всех медиа-сущностях: `tmdb_id`, `tvmaze_id`, `imdb_id`, `wikidata_id`, `anilist_id`, `shikimori_id`, `updated_at`.

Внешние ID хранятся все, а не один — чтобы не быть привязанным к источнику и иметь возможность сменить базу без потери связей.

# SEO

- Страницы генерируются на сервере и кешируются через ISR. У каждой — metadata, canonical, breadcrumbs.
- JSON-LD: `TVSeries`/`TVSeason`/`TVEpisode`, `Movie`, `BreadcrumbList`, `Article`. `FAQPage` — только там, где есть реальный FAQ.
- sitemap разбивается по типам, плюс robots.txt.
- Страница публикуется только когда есть реальные данные. Для сезона нужны даты или число серий. Иначе — noindex.
- **Никаких массовых сгенерированных страниц.** 70% страницы — реальные данные, ИИ только для пояснений, резюме и FAQ.
