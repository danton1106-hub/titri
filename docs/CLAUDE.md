# титры — бесплатный навигатор по фильмам и сериалам

@DESIGN.md
@MASTER.md

## Правила проекта

- **Бренд:** «титры», строчными. Логотип набирается текстом `[титры]` — скобки часть знака, отдельная иконка не нужна.
- **Язык интерфейса и контента:** только русский.

## Визуал

- Все цвета, типографика, отступы и радиусы — из `DESIGN.md`. Новых цветов не добавлять: система двухцветная, кремовый — единственный акцент.
- Веса: 800 — заголовки, логотип, крупные цифры; 700 — подзаголовки; 500 — текст и интерфейс.
- Трекинг: чем тяжелее вес, тем слабее минус. На весе 800 в минус не уходить.
- Фон страницы — `--bg` (тёплый почти-чёрный). Кремовая карта календаря — единственная светлая поверхность.
- Тени, свечения и градиенты на UI не использовать. Структура — волосяные линии.

## Данные

- Источники — только из списка в `MASTER.md`, только легальные и с явной лицензией. **Никаких парсеров чужих сайтов и неофициальных API.**
- В частности: Kinopoisk API Unofficial, парсинг Кино-Театр.ру и выгрузки IMDb для коммерческого использования — запрещены.
- Даты, названия и списки серий не выдумывать. Если поля нет — выводить «дата не объявлена».
- Хранить все внешние ID (`tmdb_id`, `tvmaze_id`, `imdb_id`, `wikidata_id`, `anilist_id`, `shikimori_id`), а не один.
- Атрибуция обязательна: TMDB (с формулировкой «не одобрен и не сертифицирован TMDB»), JustWatch для площадок, TVMaze, AniList, Shikimori.

## Русский контент

- База — TMDB с `language=ru-RU`, дыры закрываются через Wikidata и ручное дозаполнение в админке.
- Неофициальными API Кинопоиска дыры не закрывать ни при каких условиях.

## Статьи

- **Только собственная редакция.** Машинный перевод чужих статей и копирование запрещены — это и правовой риск, и «scaled content abuse» в глазах поиска.
- RSS используем как повод для своего текста. Формат: пересказ своими словами 2–4 абзаца со ссылкой на первоисточники.
- Тон: резковатый, чуть наглый, с собственным мнением. Без корпоративной нейтральности. Оценка важнее пересказа.
- Тон не отменяет факты: мнение — да, выдумка — нет. Критиковать можно сериал, но не людей.
- Публикация только после того, как текст написал человек. Автопубликация без редактора не допускается.

## SEO

- Реальные данные занимают около 70% страницы. ИИ — только пояснения, резюме, FAQ.
- Массовые пустые SEO-страницы не создавать. Страница выходит только когда у неё есть данные.
