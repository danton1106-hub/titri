# Обновление сайта

Данные на сайте обновляются **дважды в день: в 10:00 и 19:00 по Москве**.

## Что обновляется автоматически

| Шаг | Что делает | Источник |
|---|---|---|
| 1 | Серии, календарь, тикер главной | TMDB |
| 2 | Каталог 2026 и «скоро выходят» | TMDB |
| 3 | Рейтинги IMDb, Томатов, Metacritic | OMDb |
| 4 | Пересборка главной | — |
| 5 | Пересборка всех страниц проектов | — |
| 6 | Черновики статей | RSS |

Шаги 1–5 обязательные: если любой из них падает, сайт не перезаписывается.
Шаги 3 и 6 необязательные — без них сайт соберётся, просто без свежих рейтингов
или новых черновиков.

## Что НЕ обновляется автоматически

**Статьи не публикуются сами.** Скрипт создаёт черновик в `articles/drafts/`,
и дальше его пишет человек. Это не недоработка, а решение: машинный перевод
чужих статей — и правовой риск, и «scaled content abuse» в глазах поиска.
Подробнее в `EDITORIAL.md`.

**Рейтинги Кинопоиска и зрительский бaлл Rotten Tomatoes** не подтягиваются:
публичного доступа к ним нет. На страницах честный прочерк с пояснением.

## Про ключ OMDb

Ключ лежит в `.env` и в репозиторий не попадает.

```
OMDB_API_KEY=твой_ключ
```

**Ключ нельзя вставлять в JavaScript на странице.** Рейтинги считаются заранее
на этапе сборки, в браузер уходят готовые числа. Ключ в HTML не попадает —
это проверяется отдельно.

Бесплатный тариф OMDb — 1000 запросов в сутки, у нас 209 проектов.
Поэтому рейтинги обновляются раз в неделю, а не дважды в день: они
и не меняются так быстро. Внутри скрипта свой кэш на 7 дней.

## Запуск вручную

```bash
python3 scripts/update_all.py
```

Отдельные шаги:

```bash
python3 scripts/fetch_home.py       # данные главной
python3 scripts/fetch_catalog.py    # каталог 2026 + «скоро»
python3 scripts/fetch_ratings.py    # рейтинги через OMDb
python3 scripts/build_home.py       # сборка главной
python3 scripts/build_site.py       # сборка всех страниц
python3 scripts/collect_articles.py # черновики статей
```

## Расписание

### GitHub Actions

Файл `.github/workflows/update.yml`. **Время в workflow указывается в UTC.**
10:00 и 19:00 МСК — это **07:00 и 16:00 UTC**.

### Cron на сервере

```cron
# 10:00 и 19:00 по Москве, если сервер в UTC
0 7,16 * * * cd /путь/к/проекту && python3 scripts/update_all.py >> logs/update.log 2>&1
```

Если сервер в московском времени — `0 10,19 * * *`.

## Если что-то сломалось

Пайплайн запускает шаги по очереди и **не перезаписывает сайт, пока не пройдут
все обязательные шаги**. При сбое сайт остаётся в предыдущем состоянии —
данные не потеряны, посетитель видит рабочую версию.

**Кэш ответов TMDB:** `data/cache.json`. Если данные выглядят странно —
удалить и запустить заново, скачается свежее.

**Кэш рейтингов:** `data/ratings.json`. Форсировать обновление можно,
удалив файл или снизив `REFRESH_DAYS` в `scripts/fetch_ratings.py`.
