# титры

Бесплатный навигатор по фильмам и сериалам: **что выходит, когда выходит и где смотреть.**

Ядро — каталог 2026 года и графики выхода серий. Всё основное бесплатно,
без подписки и регистрации.

**Сайт:** https://danton1106-hub.github.io/titri

## Что внутри

| Раздел | Содержимое |
|---|---|
| **Главная** | Тикер «сегодня вышло», подборка, кремовая карта календаря |
| **Все фильмы и сериалы 2026** | 132 проекта с фильтрами по типу, жанру, стране и рейтингу |
| **Скоро выходят** | 88 проектов с датами до конца 2027 года |
| **Страницы проектов** | 203 штуки: постер, описание, факты, рейтинги, похожее |

В каталог попадают не только новинки 2026-го: если у сериала прошлых лет
выходит новый сезон в этом году, он тоже там. Это и есть главное отличие
от обычных «списков года».

## Данные

Только легальные источники с явной лицензией. Никаких парсеров чужих сайтов
и неофициальных API.

- **TMDB** — фильмы, сериалы, сезоны, эпизоды, постеры, русские названия
- **OMDb** — IMDb, Rotten Tomatoes, Metacritic
- **TVMaze** — сверка дат эфира
- **Wikidata** (CC0) — факты, которых нет в TMDB
- **RSS изданий** — повод для собственных статей

Атрибуция обязательна: TMDB, JustWatch, TVMaze, OMDb.

## Статьи

**Только собственная редакция.** Машинный перевод чужих статей не делаем —
это и правовой риск (перевод = производное произведение), и «scaled content
abuse» в глазах поиска.

Как работает: скрипт обходит 14 RSS-источников, убирает дубли, ставит ссылки
и создаёт черновик. Текст пишет человек. См. `EDITORIAL.md`.

## Стек

Статический сайт: Python собирает HTML из данных TMDB и OMDb.
Хостинг — GitHub Pages. Обновление — дважды в день, в 10:00 и 19:00 МСК.

```
scripts/fetch_home.py       данные для главной
scripts/fetch_catalog.py    каталог 2026 и «скоро выходят»
scripts/fetch_ratings.py    рейтинги через OMDb
scripts/build_home.py       сборка главной
scripts/build_site.py       сборка всех страниц
scripts/collect_articles.py черновики статей
scripts/update_all.py       всё вместе
```

Полный прогон — 40 секунд.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env      # вписать свои ключи
python3 scripts/update_all.py
```

Ключи живут только в `.env`, в репозиторий не попадают.

Подробности: `UPDATES.md` — расписание и устройство.
`EDITORIAL.md` — как писать статьи.
`MASTER.md` — архитектура и источники данных.
`DESIGN.md` — дизайн-система.
