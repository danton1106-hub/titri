# титры

Бесплатный навигатор по фильмам и сериалам: что выходит, когда выходит и где смотреть.

Новости и анонсы, календарь премьер, графики выхода серий и сезонов, блоки «сегодня вышло» и «на этой неделе», трейлеры, подборки, мини-разборы, площадки показа и SEO-материалы под конкретные фильмы и сериалы.

Всё основное — календари, графики, карточки и статьи — бесплатно и без подписки.

## Состояние

Дизайн и прототип. Бэкенда и фреймворка пока нет: главная собрана статическим HTML на реальных данных TMDB, чтобы проверить вёрстку и структуру.

**Демо:** https://danton1106-hub.github.io/titri/ — после включения GitHub Pages (см. ниже).

## Структура

```
DESIGN.md      дизайн-система: цвета, типографика, веса, компоненты, правила
MASTER.md      архитектура: стек, БД, URL, источники данных, SEO, порядок работ
CLAUDE.md      правила проекта для Claude Code
fonts/         Onest + OFL.txt — лицензия обязана лежать рядом с файлом шрифта
data/          снимки данных TMDB (JSON)
scripts/       сборщики страниц на Python
preview/       собранный HTML и CSS
docs/          то, что отдаёт GitHub Pages (index.html — автономная сборка главной)
```

## Быстрый старт

```bash
pip install -r requirements.txt
cp .env.example .env                  # свой ключ TMDB — необязательно
python3 scripts/fetch_home.py         # обновить данные из TMDB
python3 scripts/build_home.py         # собрать главную
python3 scripts/build_standalone.py   # собрать автономную версию для docs/
```

`docs/index.html` и `preview/titry-home-standalone.html` — автономные файлы: CSS встроен, шрифт вшит как base64. Открываются двойным кликом, сервер не нужен. Для картинок нужен интернет (CDN TMDB).

## Дизайн

Тёмная система на двух цветах: тёплый почти-чёрный холст, единственный кремовый акцент. Кремовая карта календаря — единственная светлая поверхность. Один шрифт, четыре ступени жирности (800 / 700 / 500), волосяные линии вместо теней.

Эволюция системы, отменённые правила и токены — в [DESIGN.md](DESIGN.md).

## Шрифт

**Onest** — лицензия SIL Open Font License 1.1, коммерческое использование разрешено. Файл шрифта и текст лицензии лежат в `fonts/`. Лицензия встраивание в сайт разрешает прямо, поэтому шрифт подключён локально, без внешнего CDN.

## Источники данных

Только легальные источники с явной лицензией. Никаких парсеров и неофициальных API — полный список и правила в [MASTER.md](MASTER.md).

- [TMDB](https://www.themoviedb.org/) — фильмы, сериалы, сезоны, эпизоды, постеры, русские названия. Этот продукт использует TMDB API, но не одобрен и не сертифицирован TMDB.
- [JustWatch](https://www.justwatch.com/) — площадки показа. Требует атрибуции при отображении.
- [TVMaze](https://www.tvmaze.com/) — расписание эфира.
- [Wikidata](https://www.wikidata.org/) — факты, CC0.

## Статьи

Только собственная редакция. Машинный перевод чужих статей и копирование не используются: это и правовой риск, и «scaled content abuse» в глазах поиска. RSS-фиды служат поводом для собственного текста со ссылкой на первоисточники.
